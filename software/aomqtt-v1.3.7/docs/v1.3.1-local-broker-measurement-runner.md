# v1.3.1 Local Broker Measurement Runner

v1.3.1 introduces a local broker measurement runner and a unified measurement
CSV schema.

## Purpose

The goal is to collect the following measurements in a comparable format:

- plain MQTT baseline;
- AOMQTT basic;
- AOMQTT fixed padding;
- AOMQTT fixed padding with token rotation and overlap;
- v1.2.0 multi-signature control-plane scenario.

## Unified output

The main output is:

```text
results/<run_id>/unified_measurements.csv
```

This CSV normalizes data-plane and control-plane measurements into a common
schema.  It is intended for paper tables and cross-scenario comparison.

## Safe default mode

The default runner mode is `sample`, which generates deterministic sample rows
without sending network traffic.

```bash
RUN_ID=run-v131-local-measurements-001 \
MODE=sample \
./experiments/run_v131_local_measurements.sh
```

## Plan mode

```bash
RUN_ID=run-v131-local-measurements-001 \
MODE=plan \
./experiments/run_v131_local_measurements.sh
```

## Actual local broker measurement

Actual MQTT measurement should be run only against local or explicitly
authorized brokers.  The plain MQTT helper can be used as a first local broker
smoke test.

```bash
python experiments/run_v131_plain_mqtt_measurement.py \
  --run-id run-v131-plain-local-001 \
  --broker localhost \
  --port 1883 \
  --count 100 \
  --qos 1 \
  --raw-csv results/run-v131-plain-local-001/raw/plain_mqtt_baseline.csv \
  --summary-json results/run-v131-plain-local-001/summaries/plain_mqtt_baseline.json
```

Then collect summaries:

```bash
python experiments/run_v131_local_measurements.py \
  --run-id run-v131-plain-local-001 \
  --out-dir results/run-v131-plain-local-001 \
  --mode collect

python experiments/collect_v131_measurement_table.py \
  --result-dir results/run-v131-plain-local-001
```
