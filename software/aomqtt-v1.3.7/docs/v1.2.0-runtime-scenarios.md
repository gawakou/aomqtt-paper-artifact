# v1.2.0 Runtime Multi-Signature and Transparency Scenarios

The v1.2.0 runtime scenario runner validates the following control-plane cases:

| Scenario | Expected result |
|---|---|
| 2-of-2 controller + security policy | accepted |
| threshold not met | rejected |
| required role missing | rejected |
| revoked signer | rejected |
| invalid signature | rejected |
| unsafe padding after valid multi-signature | rejected |

Run:

```bash
RUN_ID=run-v120-multisig-transparency-001 ./experiments/run_v120_multisig_transparency_scenarios.sh
```

Expected summary:

```text

  OK: 1
```
