# v1.2.0 Release Notes Draft

## Title

Multi-Signature Policy Authorization and Transparency Logging

## Summary

v1.2.0 introduces multi-signature policy envelopes and a lightweight
transparency log for AOMQTT control-plane policies.

This version builds on v1.1.0, which added trusted signer validation, key
revocation handling, and runtime trust scenarios. v1.2.0 raises the trust model
from single-controller authorization to multi-party policy authorization.

## Added

- `aomqtt/multisig_policy.py`
  - v1.2.0 multi-signature policy envelope creation
  - threshold validation
  - required role validation
  - duplicate signer rejection
  - KRL-aware signer validation
  - multi-signature ACK generation

- `aomqtt/transparency_log.py`
  - policy digest generation
  - hash-chained transparency log entries
  - JSONL export/import
  - chain verification
  - tamper detection

- `examples/multisig_transparency_demo.py`

- Tests for multi-signature validation and transparency log verification.
