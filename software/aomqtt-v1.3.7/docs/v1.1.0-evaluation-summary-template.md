# v1.1.0 Evaluation Summary Template

## Objective

The objective of this evaluation is to confirm that AOMQTT v1.1.0 correctly accepts trusted safe policies and rejects untrusted or unsafe control policies.

## Scenarios

| Scenario | Expected result | Expected reason_code |
|---|---|---|
| Safe policy signed by trusted key | accepted | OK |
| Policy signed by unknown key | rejected | UNKNOWN_SIGNING_KEY |
| Policy signed by revoked key | rejected | REVOKED_SIGNING_KEY |
| Policy with invalid signature | rejected | POLICY_SIGNATURE_INVALID |
| Trusted but unsafe policy | rejected | PADDING_TOO_LARGE |

## Interpretation

The evaluation confirms that AOMQTT v1.1.0 accepts only safe policies signed by trusted and non-revoked keys. Policies signed by unknown keys, revoked keys, invalid signatures, or unsafe content are rejected with explicit reason codes. These results demonstrate that the control plane can preserve client-side safety even when policy deployment is misconfigured or potentially compromised.
