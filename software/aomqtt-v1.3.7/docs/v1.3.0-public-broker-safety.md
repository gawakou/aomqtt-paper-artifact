# v1.3.0 Public Broker Safety Policy

Public broker evaluation is limited to compatibility probing.

## Allowed

- Very low-rate publish/subscribe compatibility checks.
- A small number of messages.
- Tests that comply with broker usage policies.
- Tests with explicit permission when required.

## Disallowed

- DoS-like workloads.
- Policy storms.
- ACK storms.
- High-rate throughput experiments.
- Large-scale client fan-out.
- Any traffic designed to degrade third-party infrastructure.

## Recommended limit

```text
messages: 10
rate: <= 1 message/sec
purpose: compatibility only
```

All high-rate, stress, or adversarial evaluation must be performed on local,
owned, or explicitly authorized infrastructure.
