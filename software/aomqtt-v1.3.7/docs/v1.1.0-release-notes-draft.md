# v1.1.0 Release Notes Draft

## Theme

Trusted Policy Delivery and Key Lifecycle Hardening.

## Added

- Policy signer abstraction for local, remote, and mock KMS signing.
- Signed policy envelope verification with `signer_key_id`, signature algorithm, and signing method metadata.
- Key Revocation List support for rejecting policies signed by revoked keys.
- Control policy trust bridge for raw MQTT control payloads.
- Trusted Control Policy Processor for combining trust-layer validation with the existing Policy Guard.
- Controller anomaly detection for rejected ACK spikes and dangerous reason codes.
- Runtime trust scenario runner for accepted, unknown-key, revoked-key, invalid-signature, and unsafe-policy cases.

## Research positioning

v1.1.0 extends the v1.0.2 client-side Policy Guard by adding signing-key lifecycle control and Controller-side anomaly visibility. The target threat model includes compromised signing keys, stale Controller keys, unauthorized policy issuers, and unsafe policy deployment attempts.
