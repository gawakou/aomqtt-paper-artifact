# v1.3.2 Repeated Trials and Statistics

v1.3.2 adds repeated-trial statistics for v1.3.1 local broker measurement
results.

## Purpose

v1.3.1 introduced single-run local broker measurements.  v1.3.2 aggregates
multiple trials and produces statistical summaries for paper evaluation.

## Inputs

The main input is one or more v1.3.1 comparison tables:

```text
results/<trial-run-id>/v131_local_comparison_table.csv
```

or trial directories that contain this file.

## Outputs

```text
results/<run_id>/repeated_trial_measurements.csv
results/<run_id>/repeated_trial_statistics.csv
results/<run_id>/v132_paper_statistics_table.csv
results/<run_id>/v132_repeated_trial_summary.json
results/<run_id>/v132_repeated_trials_manifest.json
```

## Sample-mode validation

Sample mode does not send network traffic.  It generates deterministic trial
inputs and validates the statistics pipeline.

```bash
RUN_ID=run-v132-repeated-trials-001 \
TRIAL_COUNT=5 \
./experiments/run_v132_repeated_trials.sh
```

## Real repeated trials

For real experiments, run the v1.3.1 measurement workflow multiple times and
then pass the generated comparison tables to the collector.

```bash
python experiments/collect_v132_repeated_trial_statistics.py \
  --inputs \
    results/run-v131-local-comparison-trial-01/v131_local_comparison_table.csv \
    results/run-v131-local-comparison-trial-02/v131_local_comparison_table.csv \
    results/run-v131-local-comparison-trial-03/v131_local_comparison_table.csv \
  --out-dir results/run-v132-repeated-trials-real-001
```

## Statistical metrics

The collector computes:

- number of trials;
- mean;
- standard deviation;
- standard error;
- approximate 95% confidence interval;
- min;
- max.

The paper table includes:

- delivery p95 mean and confidence interval;
- publish p95 mean and confidence interval;
- encrypted payload size average;
- MQTT expansion ratio;
- duplicate ratio;
- success ratio.
