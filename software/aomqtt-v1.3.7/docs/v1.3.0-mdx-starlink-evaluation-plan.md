# v1.3.0 mdx and Starlink Evaluation Plan

## mdx evaluation

The mdx environment should be used for authorized large-scale evaluation.

Recommended measurements:

- number of publishers and subscribers;
- publish latency;
- delivery latency;
- throughput;
- ACK aggregation latency;
- policy deployment time;
- transparency log growth;
- CPU and memory usage of broker, controller, publisher, and subscriber nodes.

## Starlink evaluation

The Starlink environment should be used for field evaluation under controlled
rates.

Recommended measurements:

- RTT;
- delivery latency;
- packet loss;
- throughput;
- handover timing if observable;
- token rotation duplicate rate;
- AOMQTT vs plain MQTT delivery behavior;
- policy deployment latency over Starlink.

## Required metadata

Each run should record:

- run_id;
- environment;
- broker location;
- client location;
- message count;
- message rate;
- QoS;
- AOMQTT mode;
- padding configuration;
- rotation configuration;
- policy mode;
- transparency log setting.
