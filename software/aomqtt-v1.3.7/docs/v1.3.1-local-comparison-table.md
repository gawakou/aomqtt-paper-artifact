# v1.3.1 Local Comparison Table

This document describes the v1.3.1 local comparison table generator.

## Purpose

The comparison table combines multiple `unified_measurements.csv` files into a
single paper-ready CSV.

Typical inputs are:

```text
results/run-v131-plain-local-6000-001/unified_measurements.csv
results/run-v131-aomqtt-basic-6000-001/unified_measurements.csv
results/run-v131-aomqtt-padding512-6000-001/unified_measurements.csv
results/run-v131-aomqtt-padding512-rotation30-overlap5-6000-001/unified_measurements.csv
```

## Usage

```bash
python experiments/collect_v131_local_comparison_table.py
```

The default output directory is:

```text
results/run-v131-local-comparison-6000-001/
```

Generated artifacts:

```text
unified_measurements.csv
v131_local_comparison_table.csv
v131_local_comparison_summary.json
v131_local_comparison_manifest.json
```

## Interpretation

The comparison table separates:

- logical messages;
- actual MQTT messages;
- subscriber-side duplicates;
- publisher-side rotation overlap duplicates;
- p95 delivery latency;
- p95 publish completion time;
- encrypted payload size.

For rotation scenarios, publisher-side MQTT expansion and subscriber-side
observed duplicates may differ. They should be reported separately.
