# v1.2.1 Paper Evaluation Plan

This document describes how v1.2.1 evaluation artifacts can be used in a paper.

## Evaluation Question 1: Security evolution

How does AOMQTT's control-plane protection evolve across releases?

Use:

```text
security_evolution_table.csv
```

This table summarizes the main protection, trust model, rejection coverage, and
auditability of v1.0.2, v1.1.0, and v1.2.0.

## Evaluation Question 2: Policy decision correctness

Does AOMQTT accept only valid policies and reject unsafe or untrusted policies
with explicit reason codes?

Use:

```text
policy_decision_matrix.csv
```

This table maps each policy condition to the expected decision, reason code, and
observed count.

## Evaluation Question 3: Paper-ready summary

What concise evidence can be shown in a paper table?

Use:

```text
paper_summary_table.csv
```

This table summarizes test count, scenario totals, rejection counts, and
transparency-log verification results.
