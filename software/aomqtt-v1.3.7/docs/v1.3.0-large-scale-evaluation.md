# v1.3.0 Large-Scale and Adversarial Evaluation

v1.3.0 introduces a safe evaluation framework for large-scale, adversarial,
public broker, mdx, and Starlink evaluation planning.

## Safety principle

DoS-like or high-rate workloads must be limited to local or explicitly
authorized environments. Public brokers must be used only for low-rate
compatibility probing.

## One-command evaluation

```bash
RUN_ID=run-v130-large-scale-evaluation-001 \
./experiments/run_v130_evaluation.sh
```

This command generates:

```text
large_scale_scenario_plan.csv
large_scale_scenario_plan.json
environment_safety_matrix.csv
environment_safety_matrix.json
v130_large_scale_summary.json
v130_release_table.csv
v130_release_table.json
v130_evaluation_manifest.json
```

## Scenario classes

- Plain MQTT baseline
- AOMQTT basic
- AOMQTT fixed padding
- AOMQTT token rotation
- Multi-signature control-plane batch
- Controlled local policy storm
- Controlled local ACK storm
- Public broker compatibility probe
- Starlink field evaluation
- mdx authorized evaluation
