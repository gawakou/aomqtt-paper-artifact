# v1.1.0 Trusted Control Policy Processor

`TrustedControlPolicyProcessor` is the runtime bridge for connecting the v1.1.0 trust layer to the existing v1.0.2 Control Receiver and Policy Guard.

## Purpose

The processor keeps the existing MQTT Control Receiver small:

1. receive raw MQTT control-policy payload
2. call `processor.process_payload(msg.payload)`
3. publish `result.ack`
4. if `result.accepted` is true, apply `result.policy`

## Recommended Control Receiver pattern

```python
from aomqtt.trusted_control_processor import TrustedControlPolicyProcessor

processor = TrustedControlPolicyProcessor(
    trusted_public_keys=trusted_public_keys,
    krl=current_krl,
    client_id=client_id,
    require_signature=True,
    policy_validator=existing_policy_guard_adapter,
)

result = processor.process_payload(msg.payload)
publish_control_ack(result.ack)

if not result.accepted:
    return

apply_policy(result.policy)
```

## Policy Guard adapter

The `policy_validator` may return several simple forms:

```python
# accept
return None
return True
return "OK"
return {"accepted": True}

# reject
return False
return "PADDING_TOO_LARGE"
return {"accepted": False, "reason_code": "PADDING_TOO_LARGE"}
return (False, "ROTATION_INTERVAL_TOO_SHORT")
```

If the validator raises an exception, the processor emits a final rejected ACK with:

```text
POLICY_GUARD_EXCEPTION:<ExceptionClass>
```

## Final ACK semantics

The ACK returned by `TrustedControlPolicyProcessor` is final for the received policy. It includes both trust-layer rejections and Policy Guard rejections.

Examples:

```text
UNKNOWN_SIGNING_KEY       trust layer rejection
REVOKED_SIGNING_KEY       trust layer rejection
POLICY_SIGNATURE_INVALID  trust layer rejection
PADDING_TOO_LARGE         Policy Guard rejection
ROTATION_INTERVAL_TOO_SHORT Policy Guard rejection
OK                        accepted
```

## Anomaly report

The processor records final ACKs and can export anomaly reports:

```python
processor.write_anomaly_reports("results/<run_id>")
```

This generates:

```text
controller_anomaly_report.csv
controller_anomaly_report.json
```
