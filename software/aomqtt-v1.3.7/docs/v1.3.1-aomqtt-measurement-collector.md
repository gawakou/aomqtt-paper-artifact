# v1.3.1 AOMQTT Measurement Collector

This collector converts AOMQTT publisher/subscriber metrics into the v1.3.1
unified measurement schema.

## Input files

```text
results/<run_id>/raw/publisher_metrics.csv
results/<run_id>/raw/subscriber_metrics.csv
```

The subscriber file is produced by `subscriber_example.py --delivery-csv`.

The publisher file is produced by `publisher_example.py --metrics-csv`.

## Basic usage

```bash
python experiments/collect_v131_aomqtt_measurement.py \
  --run-id run-v131-aomqtt-basic-6000-001 \
  --scenario-id aomqtt_basic \
  --publisher-csv results/run-v131-aomqtt-basic-6000-001/raw/publisher_metrics.csv \
  --subscriber-csv results/run-v131-aomqtt-basic-6000-001/raw/subscriber_metrics.csv \
  --summary-json results/run-v131-aomqtt-basic-6000-001/summaries/aomqtt_basic.json
```

Then collect into the unified CSV:

```bash
python experiments/run_v131_local_measurements.py \
  --run-id run-v131-aomqtt-basic-6000-001 \
  --out-dir results/run-v131-aomqtt-basic-6000-001 \
  --mode collect

python experiments/collect_v131_measurement_table.py \
  --result-dir results/run-v131-aomqtt-basic-6000-001
```
