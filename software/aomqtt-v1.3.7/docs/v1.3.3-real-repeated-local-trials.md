# v1.3.3 Real Repeated Local Trials Automation

v1.3.3 automates real repeated local broker measurements.

## Purpose

v1.3.1 introduced local measurement collection.  v1.3.2 introduced repeated
trial statistics.  v1.3.3 connects both by automating repeated local trials.

The automation can run:

- plain MQTT baseline;
- AOMQTT basic;
- AOMQTT fixed padding;
- AOMQTT fixed padding with token rotation and overlap;
- local comparison table generation;
- repeated-trial statistics collection.

## Safety

By default, the runner accepts only local brokers:

```text
localhost
127.0.0.1
::1
```

Use `--allow-non-local-broker` only for explicitly authorized environments.

## Dry run

Dry run is the default.  It generates a plan but does not send MQTT traffic.

```bash
RUN_ID=run-v133-real-local-repeated-001 \
TRIAL_COUNT=3 \
COUNT=100 \
EXECUTE=0 \
./experiments/run_v133_real_repeated_trials.sh
```

## Execute real local trials

Start a local broker first.

```bash
docker compose up -d
docker compose ps
```

Then run:

```bash
RUN_ID=run-v133-real-local-repeated-001 \
TRIAL_COUNT=3 \
COUNT=6000 \
EXECUTE=1 \
./experiments/run_v133_real_repeated_trials.sh
```
