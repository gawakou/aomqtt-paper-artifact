# AOMQTT v1.1.0 Release Checklist

## Release theme

**v1.1.0: Trusted Policy Delivery and Key Lifecycle Hardening**

This release extends the v1.0.2 client-side policy guard by adding a policy trust layer for signing-key lifecycle management, key revocation handling, and controller-side anomaly reporting.

## Implemented components

- Signing abstraction
  - `PolicySigner` interface
  - local Ed25519 signer
  - remote HTTP signer interface
  - mock KMS signer
- Key Revocation List (KRL)
  - revoked signing key rejection
  - KRL validation support
- Policy trust verification
  - trusted signing key check
  - unknown signing key rejection
  - revoked signing key rejection
  - invalid signature rejection
- Control policy trust bridge
  - raw MQTT control-policy payload verification
  - ACK-compatible accept/reject result generation
- Trusted control policy processor
  - trust verification plus policy guard integration
  - final ACK generation
- Runtime trust scenarios
  - accepted policy
  - unknown signing key
  - revoked signing key
  - invalid signature
  - unsafe policy rejected by policy guard
- Controller anomaly reporting
  - CSV/JSON anomaly reports
  - reason-code aggregation

## Paper-ready contribution statement

AOMQTT v1.1.0 strengthens policy delivery by separating policy signing from policy generation, supporting signing-key revocation, and detecting abnormal policy deployment behavior on the controller side. This enables clients to reject unsafe or untrusted policies even when the policies are syntactically valid, and provides traceable ACK/anomaly artifacts for evaluation.
