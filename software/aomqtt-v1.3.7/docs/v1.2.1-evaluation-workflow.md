# v1.2.1 Evaluation Workflow

v1.2.1 focuses on evaluation reproducibility and paper-ready summaries rather
than adding new security primitives.

## Purpose

The goal is to make the security evolution from v1.0.2 to v1.2.0 measurable
and easy to cite in papers.

- v1.0.2: client-side Policy Guard against unsafe controller policies
- v1.1.0: trusted signing key validation and KRL-based key revocation
- v1.2.0: multi-signature policy authorization and transparency-log auditability

## One-command evaluation

```bash
RUN_ID=run-v121-evaluation-reproducibility-001 \
./experiments/run_v121_security_evolution.sh
```

This command runs:

1. unit tests;
2. v1.1.0 trusted policy delivery scenario;
3. v1.2.0 multi-signature and transparency scenario;
4. security evolution table generation;
5. policy decision matrix generation;
6. paper summary table generation.
