# AOMQTT Source Snapshot

This directory contains the exact tracked source snapshot evaluated in the paper.

- Software: AOMQTT v1.3.7
- Evaluated Git commit: `6dc0b2c497098aca569a636d1f8f8bb2adc4253a`
- Snapshot path: `software/aomqtt-v1.3.7/`

The snapshot was exported with `git archive` from the evaluated commit. It
therefore contains only files tracked by Git at that revision and excludes the
source repository's `.git` directory, virtual environments, untracked
experiment outputs, caches, and machine-local state.

The E1 journal replication and E2 multi-client evaluation reported in the paper
were executed against this AOMQTT revision.
