# E1 Summary Tables

These files provide directly viewable summaries of the journal-level
AOMQTT v1.3.7 E1 replication dataset.

Source dataset:

../e1-v137-replication-public.tar.gz

Analyzer:

../../../evaluation/source/e1/b8_e1_v137_analyze.py

Files:

- `run_summary.csv`: per-run metrics for A1--A4, five runs per condition
- `condition_summary.csv`: aggregate metrics by experimental condition
- `summary.txt`: human-readable aggregate summary

The summaries were generated from the public sanitized E1 archive.
No experimental measurement data were modified during summary generation.

Evaluated software:

AOMQTT v1.3.7
